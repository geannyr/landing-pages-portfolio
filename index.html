Sobre o portfólio

Um portfólio técnico, não um catálogo genérico.

Cada landing page deste repositório é um projeto fictício completo, criado para demonstrar organização de código, HTML semântico, CSS responsivo e atenção a acessibilidade — do primeiro wireframe ao detalhe de foco em um botão.

Para recrutadoresLanding pages completas para avaliar organização, semântica e cuidado com detalhes de código.
Para clientesReferência de estilo e qualidade para orçar projetos de landing page parecidos.
Conteúdo fictícioMarcas, profissionais, textos e dados apresentados são demonstrativos.

Processo

Como cada landing page é construída.

  1. 1Descoberta e conteúdo

    Definição do segmento, objetivo da página e mensagem principal.

  2. 2Arquitetura da informação

    Organização das seções e hierarquia de conteúdo.

  3. 3UI e responsividade

    Layout mobile-first, testado em múltiplos tamanhos de tela.

  4. 4Acessibilidade e revisão

    Checklist de teclado, contraste, semântica e performance.

Tecnologias e critérios

Stack simples, critérios rígidos.

Stack

  • HTML5 semântico
  • CSS3 (custom properties, grid, flexbox)
  • JavaScript puro
  • Zero build

Qualidade

  • Mobile-first
  • Contraste AA
  • Navegação por teclado
  • Sem dependências externas
