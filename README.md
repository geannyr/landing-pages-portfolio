# Landing Pages Portfolio

Projeto de portfólio com quatro landing pages fictícias, criado para demonstrar organização, HTML semântico, CSS responsivo e JavaScript puro sem etapa de build.

## Landing pages previstas

- Saúde: Clínica Plena, clínica multidisciplinar. Status: em desenvolvimento funcional nesta etapa.
- Vendas: plataforma SaaS para pequenos negócios. Status: planejada.
- Jurídico/corporativo: consultoria empresarial. Status: planejada.
- Educação: plataforma preparatória. Status: planejada.

## Tecnologias

- HTML5
- CSS3
- JavaScript puro
- Sem frameworks
- Sem dependências de build
- Sem bibliotecas externas

## Estrutura

```text
landing-pages-portfolio/
├── docs/
├── saude/
│   ├── index.html
│   ├── css/
│   ├── js/
│   └── assets/
├── saas/
├── consultoria/
└── educacao/
```

## Como executar localmente

Abra `saude/index.html` diretamente no navegador. Como o projeto não usa build nem dependências, não é necessário instalar pacotes.
